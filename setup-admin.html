Guia de ativação

Esta tela separa o que já está pronto no sistema do que depende de contas, credenciais ou confirmações suas. Siga de cima para baixo; não precisa fazer tudo de uma vez.

Ver diagnóstico
1

Evolution API — WhatsApp comercial assistido

Verificando

Esta integração envia mensagens comerciais preparadas no CRM depois de você revisar e aprovar.

  1. Abra o painel da sua Evolution API no servidor/VPS.
  2. Localize a URL pública da Evolution API, a API Key e o nome exato da instância conectada.
  3. No Supabase, abra Edge Functions → Secrets.
  4. Cadastre os três segredos abaixo usando exatamente estes nomes.
EVOLUTION_API_URL
EVOLUTION_API_KEY
EVOLUTION_INSTANCE

Depois, volte aqui e clique em Atualizar status. O sistema fará um teste de conexão sem enviar mensagem.

Não me envie a API Key pelo chat. Digite a chave diretamente nos Secrets do Supabase.
2

Google — entrar com Google

Verificando
  1. Abra o Google Cloud / Google Auth Platform com a conta que administrará o acesso da Biasuz.
  2. Crie um OAuth Client do tipo Web application.
  3. Em Authorized JavaScript origins, adicione:
https://bia.dunihub.online

Em Authorized redirect URIs, adicione:

https://hszbmroogcciopipjijk.supabase.co/auth/v1/callback
  1. Copie o Client ID e o Client Secret.
  2. No Supabase abra Authentication → Sign In / Providers → Google.
  3. Ative o Google, cole Client ID/Secret e salve.
3

Discord — entrar com Discord

Verificando
  1. Abra o Discord Developer Portal e clique em New Application.
  2. Abra OAuth2.
  3. Em Redirects, adicione o callback abaixo e salve.
https://hszbmroogcciopipjijk.supabase.co/auth/v1/callback
  1. Copie Client ID e Client Secret.
  2. No Supabase abra Authentication → Sign In / Providers → Discord.
  3. Ative, cole as credenciais e salve.
4

Telegram — login por OpenID Connect

Verificando
  1. No Telegram, abra @BotFather e escolha/crie o bot da Biasuz.
  2. Abra a configuração Login Widget.
  3. Cadastre as URLs permitidas:
https://bia.dunihub.online
https://hszbmroogcciopipjijk.supabase.co/auth/v1/callback
  1. Anote Client ID e Client Secret mostrados pelo BotFather.
  2. No Supabase abra Authentication → Sign In / Providers → Custom Providers → New Provider.
  3. Escolha OIDC, identificador custom:telegram, issuer https://oauth.telegram.org, escopos openid profile.
  4. Salve. Depois me diga apenas “Telegram configurado”; eu ativo a chave visual do frontend.
Não precisa solicitar o escopo phone agora. Podemos adicionar depois, se houver necessidade real.
5

WhatsApp OTP — login por código

Verificando

O login por WhatsApp é diferente da Evolution API. No Supabase, o canal WhatsApp para OTP precisa de um provedor compatível; para WhatsApp, use Twilio ou Twilio Verify.

  1. Crie ou acesse sua conta Twilio.
  2. Habilite o remetente/WhatsApp conforme o fluxo da Twilio.
  3. No Supabase abra Authentication → Sign In / Providers → Phone.
  4. Ative Phone Auth e configure Twilio/Twilio Verify.
  5. Revise rate limits e proteção contra abuso antes de liberar para todos.
Esta etapa pode ficar para depois. E-mail/senha e OAuth funcionam independentemente dela.
6

Logomarcas e banners das representadas

Verificando

Envie preferencialmente PNG com fundo transparente, SVG ou WebP. Para banners, use horizontal em torno de 1600×600 ou maior.

7

Operação comercial

Verificando

Depois dos acessos, feche a configuração operacional:

  1. Vincular cada vendedor a um usuário do Painel do Representante.
  2. Cadastrar metas por vendedor/período.
  3. Cadastrar regras de comissão.
  4. Registrar consentimentos de WhatsApp para campanhas em massa.
  5. Subir os catálogos oficiais e revisar produtos/preços antes de publicar.

Segredos e senhas nunca devem ser colocados no código público, no GitHub ou em mensagens de atendimento. O sistema foi preparado para manter as credenciais sensíveis no Supabase e nos próprios provedores.
